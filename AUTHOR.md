## 💡 About this Project

This project was built to simplify, automate, and secure the process of provisioning Always-Free Oracle Cloud Infrastructure (OCI) ARM and AMD compute instances. It solves the notorious `Out of host capacity` error by providing a resilient, cloud-hosted 24/7 sniper with real-time Telegram alerts and zero running cost.
